# PICAAD 실험 결과 정리 (10/22 ~ 10/28)

## 공통 프로토콜

| 항목 | 설정 |
|---|---|
| 데이터 | PSM / SMD 28개 entity / SWaT 51변수 5배 다운샘플(SWaT_ds5) |
| 분할 | train 앞 80% 학습, 뒤 20% validation (모든 모델 동일) |
| 정규화·PCMCI+ | train 앞 80%에서만 fit |
| PICAAD 학습 | 80 epoch, batch 512, LR PSM 5e-5 / SMD·SWaT 5e-4, seed 0–3 |

| 평가 | point label, A-PR = sklearn AP, VUS window = 이상 구간 길이의 중앙값 |

- 지표 순서: F1, R-F1, Aff-F, A-ROC, A-PR, V-ROC, V-PR
- **new base** = prior alignment loss(tew+teg) OFF, **old base** = ON

## 2. Prior alignment loss OFF 검증 → new base로 채택

판정 기준: SWaT_ds5와 SMD28에서 A-PR·V-PR 하락이 모두 1pp 이내 → **통과**

| 데이터셋 | ΔA-PR (OFF − ON) | ΔV-PR (OFF − ON) |
|---|---|---|
| PSM | **+4.28** | **+3.49** |
| SWaT_ds5 | −0.64 | −0.09 |
| SMD28 | −0.12 | −0.06 |

PSM에서 score 성분별로 나누어 본 결과입니다(epoch 80 고정).

| score | ON A-PR | OFF A-PR | ON − OFF |
|---|---|---|---|
| A = P+C | 53.93 | 58.03 | −4.10 |
| P_raw | 53.95 | 57.99 | −4.04 |
| C_raw | 39.12 | 34.59 | **+4.53** |

- alignment를 켜면 C는 좋아지고 P는 나빠집니다. A에서는 P가 지배적입니다.

## 4. Folded Routing (PSM, new base)

변경 내용: forward bias 0.35·log W를 제거하고 ψ 초기값에 합쳤습니다(0.25 → 0.60). 나머지 구성은 같습니다.

### 구현 검증

| 항목 | 결과 |
|---|---|
| 옵션 OFF vs 기존 코드 | bitwise 동일 |
| 초기 routing weight 차이 | ≤ 1.2e-7 |
| loss 차이 | pred, teg 동일 / cstruct, tew ≤ 2e-9 / perm 상대 2.5e-4 (ReLU 경계) |
| RNG, gate·Δ 학습 | 동일 |
| checkpoint 복원 | Folded·기존 모두 정상 |

### ORIGINAL vs FOLDED (best_smooth, A = P+C)

| seed | ORIGINAL A-PR / V-PR | FOLDED A-PR / V-PR | ΔA-PR | ΔV-PR |
|---|---|---|---|---|
| 0 | 60.34 / 56.28 | 50.13 / 48.12 | −10.21 | −8.16 |
| 1 | 54.52 / 51.47 | 53.12 / 50.44 | −1.41 | −1.03 |
| 2 | 60.54 / 57.12 | 58.36 / 54.78 | −2.18 | −2.34 |
| 3 | 57.46 / 53.91 | 57.58 / 54.46 | +0.12 | +0.56 |
| **평균** | **58.22±2.84 / 54.69±2.54** | **54.80±3.88 / 51.95±3.23** | **−3.42** | **−2.74** |

- 95% CI: ΔA-PR [−10.78, +3.94], ΔV-PR [−8.79, +3.30]
- 4개 seed 중 3개에서 FOLDED가 낮고, seed 0을 빼면 평균 −1.2pp입니다.
- P_raw 기준으로도 같은 결과입니다.
- **결론: 채택 근거 부족. 최종 모델은 ORIGINAL을 유지합니다.**
